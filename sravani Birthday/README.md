# Happy Birthday, Sravani!

A small, responsive birthday page made with plain HTML, CSS, and JavaScript. Open `index.html` in a browser—there is no build step or server required. Replace the sample media files below with your own; no personal photos or video are included.

## Add your photos

1. Put your pictures in the `images` folder.
2. Use these filenames, or change the matching `src` values in `index.html`:
   - `images/sravani-1.jpg`
   - `images/sravani-2.jpg`
   - `images/sravani-3.jpg`
3. Update each image's `alt` text in `index.html` to briefly describe the actual picture. The decorative placeholders disappear automatically when a matching image loads.

JPG, PNG, and WebP files work in current browsers. If using another format, update the file extension in the HTML too.

## Add a birthday video

1. Put an MP4 video in the `videos` folder named `sravani-birthday.mp4`; the built-in player will use it automatically and replace the placeholder.
2. If you prefer a different filename or format, update the `<source>` path and its `type` in `index.html`.
3. The video has native browser controls and does not autoplay.

## Personalize the message

Edit the birthday note inside the `<details>` element with `id="birthday-wish"` in `index.html`. The wish is available by tapping its summary even if JavaScript is disabled. The celebrate link also opens it and releases a small confetti burst when JavaScript is enabled.

## Accessibility and privacy

The layout adapts to mobile, keyboard focus is visible, motion effects respect the reduced-motion setting, and all media stays local. Google Fonts are an optional visual enhancement; system font fallbacks are included. No analytics or external image services are used.
